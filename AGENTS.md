# Project Instructions

## Startup

1. Read `docs/INDEX.md`.
2. Read `docs/STATUS.md`.
3. Read the active plan when one exists.
4. Query Graphify before broad repository exploration when available.

## Working rules

- Work on one bounded plan or feature at a time.
- Keep architecture decisions in `docs/decisions/`.
- Require runnable evidence before marking work complete.
- Preserve secrets and require approval for destructive or external actions.
- Do not add architecture components without a stated constraint.

## Definition of done

- Intended behavior is implemented.
- Verification actually ran and is recorded.
- Affected documentation is current.
- The next session can restart from repository artifacts.
