# Execution Plans

Plans belong in `active/` while work is in progress and `completed/` afterward.

## Active plans

- [`active/001-retrieval-first-mvp.md`](active/001-retrieval-first-mvp.md) — retrieval-first implementation plan
- [`active/002-study-oriented-ticket-backlog.md`](active/002-study-oriented-ticket-backlog.md) — GitHub-ready study and delivery tickets

Each plan must state:

- objective;
- scope and out of scope;
- verification path;
- risks and blockers;
- progress;
- open decisions;
- next action.

The active plans above define the current implementation and study backlog.
